# Part B — MVP-2 详细开发指南

# 45. MVP-2 的核心目标

MVP-1 解决的是：

> “能不能稳定打比赛？”

MVP-2 要回答：

> “能不能真正更会做题？”

所以 MVP-2 主要 KPI 不应该是：

```text
代码行数
工具数量
Agent 数量
```

而应该是：

```text
Solve Rate
Verified Solve Rate
Time To First Flag
Tool Efficiency
Wrong Submission Rate
Hint Usage
Stall Recovery Rate
```

---

# 46. MVP-2 总体架构

建议演进为：

```text
                     Control Plane
                          │
                          ▼
                    Solver Router
                          │
        ┌─────────────────┴─────────────────┐
        │                                   │
        ▼                                   ▼
   Misc Solver                         Crypto Solver
        │                                   │
        │                                   │
        ▼                                   ▼
 Artifact Reasoner                    Equation Reasoner
        │                                   │
        ├──────────────┐            ┌───────┤
        │              │            │       │
        ▼              ▼            ▼       ▼
 Semantic Tools   Visual Runtime   Math    Python
        │              │          Tools
        │              │
        │        ┌─────┴──────┐
        │        │            │
        ▼        ▼            ▼
      Local CV Vision LLM Human Review
```

主 Solver 仍然可以是：

```text
DeepSeek text-only
```

视觉是 Tool。

---

# 47. MVP-2 分阶段

推荐：

```text
Phase 0  Intelligence Foundation

Phase 1  Visual Evidence Runtime

Phase 2  Misc Specialist Tooling

Phase 3  Crypto Specialist Tooling

Phase 4  State-aware Planning / Reflection

Phase 5  Model Routing / Specialist Agents

Phase 6  Benchmark / Replay / Skill Evolution
```

不要直接 Phase 5。

# 97. Hypothesis Schema


# 99. Action Score

程序层可以辅助：

```text
score =
    expectedInformationGain
  + solveProbability
  - cost
  - redundancy
```

初版不用数学很精确。

比如：

```text
HIGH info = +3
MEDIUM = +2
LOW = +1

cheap = 0
normal = -1
expensive = -2

already similar tested = -4
```

让 Agent 在多个 ProposedTest 中排序即可。
